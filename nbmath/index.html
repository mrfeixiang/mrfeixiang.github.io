01
纳米抗体 De Novo 设计概览
从骆驼科 VHH 到计算设计的范式跃迁

纳米抗体 (Nanobody / VHH) 是来源于骆驼科动物的重链抗体可变区 (VHH domain)，分子量仅约 12–15 kDa，是最小的天然抗原结合片段。与传统 IgG (~150 kDa) 和 scFv (~25 kDa) 相比，VHH 具有高稳定性、低免疫原性、易于基因工程改造等优势。

分子量
~12–15 kDa
来源
骆驼、羊驼、鲨鱼 (VNAR)
CDR 区域
CDR1, CDR2, CDR3 (CDR3 特别长)
应用
诊断、治疗、成像、NDC

传统路径需要骆驼/羊驼免疫 → 噬菌体展示 → 淘选 → 亲和力成熟，耗时 6–12 个月。De novo 计算设计利用结构生成模型（如 RFdiffusion）直接在目标表位上生成 CDR 骨架，再用序列设计模型（如 ProteinMPNN）填充氨基酸，周期压缩至数天。

核心管线 (RFantibody flow)：RFdiffusion (CDR 骨架) → ProteinMPNN (CDR 序列) → RF2/AF3 (验证过滤)

纳米抗体药物偶联物 (Nanobody-Drug Conjugate, NDC) 将细胞毒载荷通过可切割连接子与 VHH 偶联。相比 ADC，NDC 的肿瘤穿透能力更强、清除速率更快。

架构
Nb–Nb (bivalent)–PEG–cleavable linker–payload
偶联策略
Sortase A (SuperSrt) site-specific ligation
连接子
Cathepsin B cleavable + DBCO-azide click chemistry
载荷
MMAE; Cy5-DBCO for imaging
02
核心论文与里程碑
塑造纳米抗体 de novo 设计领域的关键文献

RFdiffusion 将去噪扩散概率模型 (DDPM) 应用于蛋白质骨架生成。通过在 SE(3) 上定义噪声注入过程，逐步向 Cα 坐标添加高斯噪声，再训练神经网络逆转此过程。该模型首次实现了对给定靶点表位的条件骨架设计。

q(x_t | x_{t-1}) = N(x_t; √(1−β_t)·x_{t-1}, β_t·I)
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), σ²_t·I)
Watson et al., Nature 2023 DDPM SE(3) equivariance

RFantibody 是 RFdiffusion 的抗体特化版本。在扩散训练中加入了抗体框架区 (FWR) 约束和 CDR 长度分布先验，使生成骨架的 CDR 几何形态与天然抗体数据库（SAbDab）更一致。支持固定 framework、仅扩散 CDR-H3 或全部 CDR。

关键创新：CDR-specific diffusion — 仅在 CDR loop 区域执行噪声扩散，保持 framework 不变。

ProteinMPNN 是一个消息传递神经网络 (Message Passing Neural Network)，在给定蛋白质骨架结构的条件下自回归地预测氨基酸序列。核心数学：图神经网络中的节点/边信息聚合 + 交叉熵损失的序列似然最大化。

P(S|X) = ∏ᵢ P(sᵢ | s_{<i}, X)
L = −∑ᵢ log P(sᵢ* | s_{<i}*, X)
Dauparas et al., Science 2022 GNN / MPNN Autoregressive decoding

AlphaFold3 (Abramson et al., 2024) 使用扩散模块替代 AF2 的 Structure Module，支持蛋白质-蛋白质、蛋白质-小分子的共折叠预测。Boltz-2 (Wohlwend et al., 2025) 是开源替代方案，在抗体-抗原界面预测上表现优异。在 de novo 管线中，它们用于验证设计序列是否正确折叠并结合靶标。

关键指标
ipTM, pAE_interaction, pLDDT
过滤标准
ipTM > 0.7, pAE_interaction < 10

BindCraft 将 AF2 的置信度指标 (pAE, pLDDT) 作为可微分的优化目标，直接在序列空间中进行梯度优化来设计蛋白结合体。无需先生成骨架。数学核心：softmax 温度退火 + AF2 loss 的梯度回传。

Chai-1

开源共折叠模型，抗体-抗原亲和力排序精度高

OpenDDE

抗体-抗原结合能打分模型

ESMFold / ESM-IF

大规模蛋白质语言模型的逆折叠方向

DiffAb

抗体 CDR 设计专用扩散模型

04
线性代数 × 纳米抗体设计
向量空间、矩阵运算如何驱动结构建模

每个氨基酸残基被编码为高维向量 (embedding)。在 RFdiffusion 中，残基 node features 包含坐标、残基类型 one-hot 和位置编码。整个蛋白质可表示为矩阵 X ∈ ℝ^{N×d}，其中 N 为残基数、d 为嵌入维度。

X = [x₁, x₂, ..., xₙ]ᵀ ∈ ℝ^{N×d}
xᵢ = Embed(residue_type) + PE(position)

Transformer 的自注意力在 RFdiffusion 和 AF3 中均为核心组件。Query-Key-Value 的矩阵乘法和 softmax 归一化是线性代数的直接应用。

Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V
Q = XW_Q, K = XW_K, V = XW_V
在抗体设计中，Q/K/V 矩阵编码残基间的空间距离和序列关系，注意力权重反映了残基间的接触概率。

蛋白质结构不依赖于坐标系的选择。SE(3) 等变神经网络保证：若输入旋转/平移，输出做相同变换。旋转用 3×3 正交矩阵 R ∈ SO(3) 表示，平移用向量 t ∈ ℝ³。

T = (R, t) ∈ SE(3), where R ∈ SO(3), t ∈ ℝ³
f(T·x) = T·f(x) [equivariance]
RRᵀ = I, det(R) = 1

ProteinMPNN 将蛋白质建模为 k-NN 图。邻接矩阵 A ∈ {0,1}^{N×N} 编码残基间的空间邻接关系。消息传递 (message passing) 在图上聚合邻居信息。

hᵢ^{(l+1)} = Update(hᵢ^{(l)}, Aggregate({m_{j→i} | j ∈ N(i)}))
m_{j→i} = Message(hⱼ^{(l)}, eⱼᵢ)

在纳米抗体序列空间分析中，PCA (主成分分析) 用于高维序列嵌入的降维可视化。协方差矩阵的特征值分解揭示序列变异的主要方向。

Σ = (1/n) Xᵀ X
Σ = UΛUᵀ (eigendecomposition)
05
微积分 × 结构扩散与优化
梯度下降、反向传播如何训练蛋白质生成模型

所有深度学习蛋白质设计模型的训练都依赖于损失函数的梯度最小化。Adam 优化器使用一阶和二阶矩估计自适应调节学习率。

θ_{t+1} = θ_t − η · m̂_t / (√v̂_t + ε)
m_t = β₁m_{t-1} + (1−β₁)∇L
v_t = β₂v_{t-1} + (1−β₂)(∇L)²

RFdiffusion 的正向过程可表示为随机微分方程 (SDE)。从数据分布 p_data 到高斯噪声的连续路径。反向采样对应逆时间 SDE。

dx = f(x,t)dt + g(t)dW [forward SDE]
dx = [f(x,t) − g(t)²∇_x log p_t(x)]dt + g(t)dW̄ [reverse SDE]
Score function ∇_x log p_t(x) 是扩散模型的核心 —— 训练神经网络估计此函数。

反向传播 (backpropagation) 是微积分链式法则的直接应用。在 ProteinMPNN 中，通过自回归序列生成的每一步，梯度沿计算图反向传播更新权重。

∂L/∂W₁ = (∂L/∂y) · (∂y/∂h) · (∂h/∂W₁)
[chain rule applied layer by layer]

BindCraft 将 AlphaFold2 的置信度指标 (pAE, pLDDT) 作为可微分的目标函数。通过 softmax 温度退火策略直接在序列空间中梯度优化，跳过骨架生成步骤。

L_bind = −ipTM(AF2(seq)) + λ · L_regularize
seq ← seq − η · ∂L_bind/∂seq (via Gumbel-softmax)
06
概率统计 × 序列生成与评估
贝叶斯推断、采样策略、评估指标

ProteinMPNN 和 ESM-IF 将序列设计建模为自回归条件概率。给定骨架结构 X，每个位置的氨基酸概率取决于已生成的前序残基。

P(S|X) = ∏_{i=1}^{N} P(sᵢ | s₁,...,s_{i-1}, X)
Perplexity = exp(−(1/N) ∑ log P(sᵢ*))

去噪扩散概率模型 (DDPM) 的正向过程是预定的马尔科夫链，反向过程由参数化的高斯转移核建模。ELBO (证据下界) 提供了训练目标。

ELBO = E_q[log p_θ(x₀|x₁)] − KL(q(x_T|x₀) ∥ p(x_T))
− ∑_{t=2}^{T} KL(q(x_{t-1}|x_t,x₀) ∥ p_θ(x_{t-1}|x_t))

在 ProteinMPNN 中，采样温度 T 控制序列多样性。T→0 趋于贪婪选择（最高概率），T→∞ 趋于均匀随机。Top-k 采样限制候选集大小。

P_T(sᵢ = a) = exp(logit_a / T) / ∑_b exp(logit_b / T)
ipTM
界面 pTM score — 基于残基距离误差分布的置信度估计
pAE
Predicted Aligned Error — 位置 i 相对于 j 的预测误差矩阵
pLDDT
Per-residue confidence — 对局部距离差异的分箱概率分布
Recovery rate
序列恢复率 — 设计序列与天然序列的氨基酸一致比例
07
RFdiffusion 中的数学
扩散模型在蛋白质结构空间上的数学体系

蛋白质骨架是 SE(3) 帧 (rotation + translation) 的序列。RFdiffusion 在旋转分量上施加 IGSO(3) 分布的噪声 (Isotropic Gaussian on SO(3))，在平移分量上施加标准高斯噪声。

Frame_i = (Rᵢ, tᵢ) ∈ SE(3)
Forward: R_t ~ IGSO3(R_{t-1}, σ_t), t_t ~ N(√α_t · t_{t-1}, (1−α_t)I)

去噪网络以加噪结构和时间步 t 为输入，预测干净结构。损失函数是预测帧与真实帧在 SE(3) 上的距离。

L = ∑ᵢ [ ‖t̂ᵢ − tᵢ‖² + w_R · d_SO3(R̂ᵢ, Rᵢ) ]

在纳米抗体设计中，靶标蛋白的表位残基作为条件信息传入去噪网络。这实现了"在指定表位上生成结合骨架"。数学上是条件概率 p(backbone | epitope)。

条件扩散 = classifier-free guidance 或 inpainting 策略，将表位坐标作为固定的"已知"区域。
08
ProteinMPNN 中的数学
消息传递网络的图运算与序列似然

ProteinMPNN 将蛋白质骨架表示为稀疏图 G = (V, E)。节点 = Cα 原子，边 = k 近邻 (通常 k=30)。节点特征包含二面角 (φ, ψ, ω)，边特征包含距离和方向向量。

V = {v₁, ..., vₙ}, E = {(i,j) | j ∈ KNN(i, k=30)}
Node features: (φ, ψ, ω, residue_type_onehot)
Edge features: (d_ij, unit_vector_ij, RBF(d_ij))

每层消息传递由三步组成：(1) 计算边消息，(2) 聚合邻居消息，(3) 更新节点表示。3 层堆叠捕获约 90Å 半径内的结构上下文。

mᵢⱼ = MLP_edge([hᵢ ∥ hⱼ ∥ eᵢⱼ])
Mᵢ = ∑_{j∈N(i)} mᵢⱼ
hᵢ ← MLP_node([hᵢ ∥ Mᵢ])

解码阶段按随机排列顺序逐位生成氨基酸。每步的 20 类概率通过 softmax 输出，训练目标为交叉熵损失。

logits_i = W_out · h_i^{(L)} + b
P(sᵢ = a) = softmax(logits_i)_a
L_CE = −∑ᵢ log P(sᵢ = sᵢ*)
09
结构验证中的数学 (AF3 / Boltz-2)
共折叠预测中的 pairwise 表示与置信度估计

AF3 使用 Pairformer (AF2 为 Evoformer) 处理 MSA 和 pair 表示。核心运算：行/列注意力在 pair representation z ∈ ℝ^{N×N×c} 上的三角更新 (triangle update)，数学上等价于矩阵乘积的特殊形式。

z_ij ← z_ij + ∑_k (a_ik · b_kj) [outgoing triangle]
z_ij ← z_ij + ∑_k (a_ki · b_kj) [incoming triangle]

AF3 用扩散模型替代了 AF2 的 Structure Module。在原子坐标空间直接扩散，支持蛋白质、核酸、小分子和离子的联合建模。

x_atom_t = √ᾱ_t · x_atom_0 + √(1−ᾱ_t) · ε
Loss = E_t,ε [‖ε − ε_θ(x_atom_t, t, conditioning)‖²]

ipTM (interface predicted TM-score) 由链间残基对的距离误差分布计算得出。pAE 矩阵的每个元素 pAE[i,j] 表示"残基 i 在以残基 j 为参考对齐后的预测位置误差"的概率分布，取 argmax bin 作为预测值。

TM-score = (1/N) ∑ᵢ 1/(1 + (dᵢ/d₀)²)
ipTM = weighted average over interface residue pairs
10
实战：RFantibody 管线数学拆解
从表位选择到 hit 序列的端到端数学流程

选取靶蛋白表位残基 (hotspot residues)，将其坐标作为 SE(3) 条件编码传入 RFdiffusion。数学：条件概率 p(CDR_backbone | epitope_coords)。

RFantibody 在 SE(3) 上执行 T 步反向扩散，从高斯噪声中采样 CDR loop 骨架。Framework 区域保持固定。关键超参：扩散步数 T、噪声调度 β_t。

ProteinMPNN 接收生成的骨架结构，通过 GNN 编码 + 自回归解码输出 CDR 序列。采样温度 T=0.1 (保守) ~ 0.5 (多样)，通常生成 100–1000 条候选序列。

将设计序列与靶标序列一起输入 AF3 或 Boltz-2 进行共折叠预测。过滤标准：ipTM > 0.7, pAE_interaction < 10, CDR RMSD < 2Å (与设计骨架对比)。

通过通过的候选进入可开发性评估：聚集倾向、溶解度 (CamSol)、人源化评分 (Hu-mAb)、TAP 5 指标。最终按综合评分排序输出 Top-N 进入实验验证。

NabTriad 平台集成了这一完整管线：NabPanning (序列亲和力) → NabDock (AF3/MD 结构) → NabSafe (可开发性/免疫原性)
